 
 
 
# Actualmente en desarrollo

⚠️ **Nota:** El proyecto se encuentra **actualmente en desarrollo**. Se están implementando nuevas funciones y mejoras de estabilidad de forma continua.

## 🚀 Tecnologías y Enfoque
*   **Ionic Framework**: Tecnología principal utilizada para el desarrollo de la interfaz móvil.
*   **Metodología Kanban**: Flujo de trabajo estructurado en tres estados (*Por hacer*, *En proceso* y *Hecho*).

## 🛠️ Instalación y Configuración

Para ejecutar el proyecto localmente, sigue estos pasos:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com
   ```

2. **Instalar las dependencias:**
   ```bash
   npm install
   ```

3. **Ejecutar en modo de desarrollo:**
   ```bash
   ionic serve
   ```
